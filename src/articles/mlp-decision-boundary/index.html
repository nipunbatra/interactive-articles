Evidence becomes geometry

Four XOR coordinates and four filled XOR regions are not the same learning problem. Build a tiny ReLU network, inspect what every hidden unit sees, and compare the boundary learned from a handful of points with the boundary demanded across a plane.

~10 min From-scratch JavaScript · deterministic data · no ML library
Before you train

A correct answer can still leave the space between points unspecified

The Boolean XOR truth table contains four observations. A width-two ReLU network can classify all four with a diagonal band. A Playground-style XOR dataset fills the quadrants with observations; now the desired boundary is two crossing lines. The first network was not wrong—it answered a smaller question.

$$h_1=\operatorname{ReLU}(u+v),\quad h_2=\operatorname{ReLU}(-u-v),\quad z=1-h_1-h_2.$$

Here $u$ and $v$ are centred versions of $x_1$ and $x_2$. The Load proof control installs these weights. Watch its four-point accuracy and its filled-field agreement disagree, then replace four points with evidence throughout the quadrants.

Start with the two XOR buttons. The same 2-ReLU diagonal band is perfect on four corners but incomplete across filled quadrants. The missing training evidence—not a contradiction in the network—is the point of the comparison.
What to notice

The data constrain a function; they do not uniquely draw it

Think of each ReLU as a hinged half-plane: $\operatorname{ReLU}(\mathbf{w}_i^{\top}\mathbf{x}+b_i)$ is flat on one side of its line and rises on the other. The output adds those hinged surfaces. Two units can build a band; four can create the crossing required by filled XOR.

  • Four-point accuracy tests those four coordinates. It says nothing by itself about the empty space between them.
  • Filled-field agreement tests geometry. Errors inside every quadrant now contribute to the loss.
  • Activation maps expose the construction. Widening adds hinges; depth composes the regions those hinges create.
The training signal is still $\hat{y}-y$. Every gradient step nudges the weights so predictions move toward the labels, and backpropagation carries that same signal back through the hidden layer. Nothing here is magic: a stack of linear maps with a nonlinearity between them, trained by the ordinary chain rule, is enough to carve the plane into whatever the data demands.
