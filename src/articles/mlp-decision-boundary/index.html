What an MLP Can Carve

A linear classifier can only draw one straight cut across the plane. Stack a hidden layer of neurons in front of it and each neuron contributes its own line; the network stitches them into a curved, folded boundary that can wrap around circles, separate spirals, and solve XOR. Pick a dataset, press Train, and watch the boundary bend itself into shape.

~8 min Deep Learning · Multi-Layer Perceptrons · Nonlinearity
Prelude

One line is not enough

A logistic-regression classifier scores a point $\mathbf{x}=(x_1,x_2)$ with a single linear function and thresholds it:

$$\hat{y} = \sigma(\mathbf{w}^{\top}\mathbf{x} + b), \qquad \sigma(z)=\frac{1}{1+e^{-z}}.$$

The set of points where $\mathbf{w}^{\top}\mathbf{x}+b = 0$ is a straight line, and everything on one side is class 1, the other class 0. That is the only shape it can make. A multi-layer perceptron inserts a hidden layer of $H$ neurons first:

$$\mathbf{h} = \phi(W_1\mathbf{x}+\mathbf{b}_1), \qquad \hat{y} = \sigma(\mathbf{w}_2^{\top}\mathbf{h}+b_2).$$

Each hidden neuron draws its own line and passes it through a nonlinearity $\phi$ (here $\tanh$ or ReLU). The output layer then takes a weighted combination of those bent pieces. With enough neurons the boundary can approximate any region — the universal-approximation idea, made visible below.

Try the linear model on XOR and spirals. No straight line separates the classes, so accuracy stalls near 50–75% no matter how long you train — exactly the 1969 Minsky–Papert objection that stalled neural nets for a decade. Switch back to the MLP and the same data becomes easy.
The Payoff

Why hidden units bend the line

Think of each hidden neuron as a soft half-plane detector: $\phi(\mathbf{w}_i^{\top}\mathbf{x}+b_i)$ is near one value on one side of its line and near another on the other side. The output neuron adds these together with its own weights. Two neurons can already build a stripe; four can fence off a box; more can round it into a circle or chase a spiral.

  • With tanh, each unit gives a smooth ridge, so the boundary comes out curved.
  • With ReLU, each unit gives a sharp crease, so the boundary is piecewise-linear — a polygon of flat facets, still able to enclose any region if you use enough of them.
  • Widen $H$ and you add more pieces of line to spend; deepen to 2 layers and the second layer combines regions built by the first, reaching complex shapes with fewer units.
The training signal is still $\hat{y}-y$. Every gradient step nudges the weights so predictions move toward the labels, and backpropagation carries that same signal back through the hidden layer. Nothing here is magic: a stack of linear maps with a nonlinearity between them, trained by the ordinary chain rule, is enough to carve the plane into whatever the data demands.
