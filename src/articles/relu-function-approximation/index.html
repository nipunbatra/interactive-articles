ONE-DIMENSIONAL WITNESS

Build a function from ReLU hinges.

Construct an interpolant that is guaranteed by its knots, then train the same kind of network from a deterministic random start. Keep existence and optimization as separate claims.

The theorem boundary

For continuous f on a compact domain and every ε > 0, some finite one-hidden-layer ReLU network can make

supx∈D |f(x) − ĝ(x)| < ε.

This lab shows one-dimensional witnesses and optimizer runs. Its 401-point grid maximum is not an exact supremum.
